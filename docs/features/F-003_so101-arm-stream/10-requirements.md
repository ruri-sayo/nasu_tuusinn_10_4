# Requirements

### REQ-0025: ハードウェア構成の正本を固定する

covers: -
verify: test

SO-101の左右とLeader/Followerの対応、USBシリアル番号、安定デバイス名、較正ファイルは、
`NASURA2026_LeRobot_info` の指定commitに格納された情報だけを使用すること。起動処理が較正値を
生成、更新、補正しないこと。

### REQ-0026: 起動前検査で誤接続を拒否する

covers: -
verify: test

追従側アームへトルクを与える前に、ハードウェア情報のcommit、udevルール、4個の安定デバイス名、
各USBシリアル番号、4個の較正ファイル、LeRobot実行ファイルを検査すること。1項目でも不一致なら
全アームを起動せず、原因を表示して非0で終了すること。

### REQ-0027: 左右のLeaderからFollowerを追従操作する

covers: -
verify: test

左Leaderの6関節操作が左Followerへ、右Leaderの6関節操作が右Followerへ対応し、左右を同時に
最低5分間操作できること。片側の入力が反対側へ送られないこと。

### REQ-0028: 異常時にアーム出力を停止する

covers: -
verify: test

起動時に1制御周期あたりの関節位置変化を制限すること。SIGINT・SIGTERM、いずれかのアームプロセス
または映像配信プロセスの終了時には、残る全子プロセスを終了し、追従側アームを切断時トルク無効で
解放すること。物理的な最終停止は介添人による追従側アームの電源遮断とする。

### REQ-0029: アーム稼働中も既存映像配信を維持する

covers: -
verify: test

左右アームを5分間同時操作している間も、F-001のS1映像がQuestへ継続配信され、F-001のS3制御接続と
安全状態を変更しないこと。アーム制御データをWebRTCまたはF-001のUDP出力へ混載しないこと。

### REQ-0030: 試験状況を追跡可能にする

covers: -
verify: test

事前検査の結果、使用したハードウェア情報commitとLeRobot commit、左右各プロセスの標準出力・
標準エラー、開始・停止理由を時刻付きログから確認できること。ログへ較正値以外の秘密情報を記録しないこと。
