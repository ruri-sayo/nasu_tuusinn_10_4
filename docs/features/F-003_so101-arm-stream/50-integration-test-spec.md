# Integration Test Spec

### IT-0011: ハードウェア情報から左右プロセスを構成する

covers: AD-0015, AD-0016
verify: test

指定commitと同じ構造のfixture、模擬デバイス検査、模擬LeRobot実行ファイルを与える。起動記録に左右それぞれ
1個のプロセスがあり、各ID・ポート・較正root・安全引数が設計の対応表と一致すること。

### IT-0012: 事前検査失敗時は実機を駆動しない

covers: AD-0016, AD-0018
verify: test

commit不一致、udev検査失敗、4デバイス中1個欠落、較正ファイル欠落、安全確認オプション欠落の各条件で、
LeRobotと `run_car.sh` の模擬実行ファイルが一度も呼ばれず、非0終了と原因表示になること。

### IT-0013: アームと既存配信を同時管理する

covers: AD-0017, AD-0019
verify: test

左右の模擬LeRobotが初期安定時間を越えた後だけ、模擬 `run_car.sh` が1回起動すること。3子が生存中は
親も生存し、ログが子ごとに分離されること。

### IT-0014: 子プロセス異常時に全体を停止する

covers: AD-0017, AD-0018
verify: test

左右アームまたは配信の各模擬子プロセスを順に異常終了させ、残る子が終了され、親が非0で終了し、
最初の異常終了元と終了コードがログに残ること。
